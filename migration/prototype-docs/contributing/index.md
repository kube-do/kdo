# 参与贡献

文档与代码一样需要评审和门禁。贡献前先阅读以下规范：

| 主题 | 内容 |
|---|---|
| 本地开发 | 安装 Node/pnpm，启动 Docusaurus，预览改动 |
| 写作规范 | 中文技术写作、术语表、标题层级、截图规范 |
| 页面模板 | 教程、操作、参考、解释、排障、发布说明 |
| 评审流程 | PR 模板、CODEOWNERS、review SLA |
| 发布流程 | 预览环境、URL parity、上线检查 |

:::tip
每个 PR 只做一类改动：迁移、IA、内容重写或资源治理。混在一起会让 review 和回滚都变难。
:::
