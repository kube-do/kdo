# 管理指南

管理指南面向平台管理员，关注“怎么管、怎么配、怎么排障”。

| 领域 | 典型任务 |
|---|---|
| 集群 | 节点、集群接入、证书 |
| 命名空间 | Namespace、ResourceQuota、LimitRange、CRD、AppProject |
| 权限 | 用户、组、RBAC、Keycloak |
| 平台配置 | 图形化配置编辑器、组件重启 |
| 通知 | 渠道、事件类型、公告、静默时段 |
| Operator | OperatorHub、已安装 Operator |
| 存储与网络 | 存储后端、NetworkPolicy |
| 运维 | 备份恢复、排障、安全基线 |

开发者视角的日常操作在[开发指南](/docs/developer/)中，避免同一概念维护两套步骤。
